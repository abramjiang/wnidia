# 场景、应用价值与商业价值实现

## 一、这个融合体到底卖什么

**不是"更便宜的 token"，而是三样别处买不到的东西：**

| 能力 | 技术事实 | 客户听得懂的说法 | 层次 |
|---|---|---|---|
| 精确可验证推理 | 草稿只改速度不改字节；回复带 `token_sha`/`min_rows`，可用 `draft:false` 自证 | 同样输入永远同样输出，还能拿出来证明 | 引擎层 |
| 硬件后端可插拔 | 同一份 4-bit 权重覆盖 Apple Metal 与 NVIDIA CUDA 两条 ISA 路径 | 一次接入，换硬件不改代码 | 硬件层 |
| 异构调度与治理 | 注册心跳/标签路由/配额/抢占续算/FinOps/密级 L0–L4 | 闲置算力变成可计价、可调度、可审计的资源池 | 编排层 |

一句话定位：**面向「数据不出域 + 结论要可审计 + 硬件不许锁定」三重约束的私有化推理底座。**

## 二、可开发场景（15 个，按可交付时间分三层）

### 现在（0–12 个月，能开票）

| # | 场景 | 谁买单 | 为什么是它 |
|---|---|---|---|
| A1 | 单机构异构算力池化 + 引擎托管 | 50–500 人研发机构、高校实验室、设计/影视、律所 | 注册心跳 + 标签路由 + 配额本来就是这个形态；把已有 Mac/工作站变节点，**无需买卡** |
| A2 | 可复现推理留痕 | 银行风控、券商合规、律所、医院、政企内审 | 通用推理服务同一 prompt 两次结果可能不同，举证场景是致命的；逐字节一致 + `token_sha` 把它变成证据链 |
| A3 | 开发机=生产机的回归基线 | 任何做 AI 应用/Agent 的 5–50 人团队 | 跨硬件输出一致 → 回归不漂移；采购决策链最短（效率工具，不是基础设施） |
| A4 | 离线/端侧推理 | 军工、能源、医疗、涉密研究、工厂现场 | 本地 OpenAI 端点 + 断网可用 + 可举证 |
| A5 | 算力体检 + ROI 报告 | 犹豫是否建私有算力的机构 IT | before/after 同口径压测本身就是交付物；**最快的首单** |

### 近期（12–24 个月，需补门票）

- **B1 单机构算力运营（FinOps 分成）**：利用率 30%→70% 的增益按比例分成，客户零风险（需真实跨机调度 + 可信计量）
- **B2 多租户 GPU 池化私有云**：集团 IT 共享中心按部门计量结算（需生产级五层隔离 + OIDC/RBAC + 审计）
- **B3 混合推理网关**：按芯片特长拆分 prefill/decode，轻量任务放 Mac/CPU、重推理放 GB10（引擎可插拔已具备）
- **B4 科研可复现基线平台**：同一 seed 同一硬件组合 → 可复现实验，解决"论文复现不了"
- **B5 国产卡/多芯适配**：新增一个 engine 条目 + `backend` 标签即可接入，调度层零改动；抗断供是政企采购硬需求
- **B6 模型评测 / 红队 / 安全对齐服务**：**可复现是评测结论有法律效力的前提**

### 未来（24 个月+，需资本与合规双达标）

- **C1 跨机构算力撮合平台**：交易抽佣；双边网络效应护城河最深，但冷启动极难
- **C2 数据主权感知算力网络**：密级调度 + TEE 远程证明 + 密钥代理（证明不通过即拒绝执行）
- **C3 边-云协同推理网络**：Mac/Jetson/车载/机器人组成同一逻辑推理池
- **C4 Agent 时代的"可信推理计量"白标**：给 Agent 平台提供可审计的 token 账本与一致性证明（上游是客户，不是对手）
- **C5 内核/插件市场**：模型家族内核包 + Agent Skill 包分发抽成

## 三、五类买家的账

| 买家 | 真正付钱买的东西 | 可量化 | 不可量化但更要紧 |
|---|---|---|---|
| 中小企业/机构 IT | 不是省 API 费，是"可控"：不涨价、不停服、不改条款、不留数据 | 闲置设备利用率 30%→70%；运维 −1 人 | 无供应商锁定；能回答"数据去哪了" |
| 合规密集行业 | 举证能力：可复现、可审计、不出域 | 审计准备从周级降到小时级 | 通过监管检查——这是不能失败的事 |
| AI 研发团队 | 研发效率：开发与生产一致 | 回归假阳性下降；环境排查工时下降 | 不用再说"在我机器上是好的" |
| 算力持有方（机主） | 闲置资产变现 | 闲时入网按卡时/Token 分成 | 主人优先，自己的任务随时抢占 |
| Agent / SaaS 平台 | 外包推理底座 | 省下自建 3–5 人月 + 硬件 | 拿到"可信推理"合规背书，可卖给更严的客户 |

## 五、单位经济性：一个必须避开的错误论证

一台 DGX Spark 单引擎按 50 tok/s、30% 利用率：

```
4.7 亿 token/年  ×  云端 ¥2/百万 token  ≈  ¥3,150/年
硬件成本 $4,000（不含电费、运维、人力）
```

**token 单价的账算不过来。** 私有化的价值在四处，且都无法用 token 单价衡量：

1. **合规与主权溢价**——"不做就没法开展业务"的成本，不是"贵一点"的成本；
2. **研发效率**——省的是工程师工时（按人月计价，远高于 token 费用）；
3. **运维人力**——少一个专职运维、少一次线上事故，以十万计；
4. **风险对冲**——API 涨价/停服/条款变更/断供的可预测性溢价。

**所以销售第一句应该是"用你已有的机器"，而不是"比云便宜"。**
只有两种情况设备账能算平：高吞吐长文本批处理；或设备本身已是沉没成本（边际成本≈电费）。

## 六、差异化一句话

> 「我们不是又一个 Agent 平台，而是 Agent 时代**可复现、可迁移、可调度**的私有推理底座。」
>
> 三个词分别对应**引擎层**（逐字节一致 + 可自证）、**硬件层**（Metal/CUDA 双后端）、
> **编排层**（异构调度 + 数据主权分级），每一层都有可跑的实证。
