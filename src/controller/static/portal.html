层级路由

层级异构 · 云 / 边 / 端

中心 GPU 池（训练与 70B+ 重推理）、边缘算力箱（现场推理、断网自治）、端侧家庭节点（轻量推理与异步任务）。

↔ 对应场景：三维路由 · 时延/成本/密级择点
解决需求：同一任务改时延 / 成本 / 密级三个维度，验证落点随之变化且理由可解释——不同优先级的任务自动选对层。
切分调度

切分异构 · vGPU / MPS / MLX

细粒度切分与分时复用，把一块卡拆给多个租户。边界：GB10 硬件不支持 MIG，本系统给出 MPS 策略并如实标注。

↔ 对应场景：私有云资源池 · 切分与密级准入
解决需求：重推理上中心、真跑 gpu-slicer 出切分建议、L3 机密任务密级与 CC 准入、8 路并发压测——一块卡安全拆给多租户。
故障自愈

代际异构 · 跨代际混部

新旧型号同一纳管，不被单一型号绑死；硬件缺货与代际更替由网络规模兜底。

↔ 对应场景：故障自愈 · 压力场景验证
解决需求：中心中断 / 单节点掉线 / 节点不可信 / 新任务类型逐条触发并自动恢复——代际混部下的韧性兜底。
可信接入

可信异构 · 密级分级

TEE、远程证明、任务抽检与信誉分；敏感与高 SLA 任务不进入家庭节点，校验失败即撤回中心。

↔ 对应场景：家庭节点网格 · 轻量下沉与抽检
解决需求：轻量任务下沉端侧、注入作弊后多数决抽检识别并降级信誉、高密级任务拒绝下沉——不可信节点安全纳管。
边缘自治

复用异构 · 分时与抢占

推理优先、分时复用、排队抢占；高优任务抢占低优并保存 checkpoint，恢复后续算。

↔ 对应场景：边缘算力箱 · 现场推理自治
解决需求：时延优先落边缘、中心中断自动改派、断网本地续跑、联网回放补记——弱网 / 断网下现场业务不停。
