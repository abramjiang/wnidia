# WNIDIA · 战略定位与商业价值分析

> 本文档聚焦**定位与价值**，技术实现见 `HETEROGENEOUS_*` 系列文档。
> 定位结论：面向 **NVIDIA 全系列异构**的中立算力编排与计量；
> 不涉足国产算力卡（结构性理由见第 4 节）。

---

## 1. 一句话定位

> **WNIDIA 不是"某种卡的调度器"，而是跨硬件中立的算力编排与计量层。**
>
> 同一套 DeviceProfile + 路由 + 计量机制纳管不同设备，
> 新增硬件只注册画像、不改调度逻辑——纳管，而非适配。

---

## 2. 三条赛道与竞争判断

| 赛道 | 定位 | 市场刚性 | 竞争烈度 |
|---|---|---|---|
| **NVIDIA 全系列异构** | 主战场（存量巨大、可复用） | 中高 | **高** |
| AMD + 海外 NPU 异构 | 补充（避免供应商锁定） | 中 | 高 |
| ~~Apple 算力融合~~ | **已搁置**（见第 5 节） | — | — |

**现实判断**：NVIDIA 异构是**入场券不是护城河**——
NVIDIA 自身有 MIG/DCGM，云厂商有异构实例，K8s/Ray/vLLM 生态也在做。
真正的差异化在**可信计量**（多硬件混用后的算力记账，竞争者最少）。

---

## 3. 核心价值点

| 价值 | 说明 |
|---|---|
| **一次适配，多次复用** | 统一 CUDA 栈 → 适配成本 O(1)，不是 O(厂商数) |
| **按瓶颈路由** | 容量/带宽/算力分工，让便宜的卡干它擅长的活 |
| **可信计量** | 混用后"谁用了多少、花多少钱"，竞争者最少 |
| **中立性** | 不被单一供应商绑定（对应 CSU 愿景） |

---

## 4. 不涉足国产算力卡：结构性理由

> 说明：以下为**商业结构性判断**，不否定国产算力的战略意义，
> 仅论证"以异构编排为产品"时的经济性差异。

| 维度 | NVIDIA 全系列 | 国产算力异构 |
|---|---|---|
| 适配栈数量 | **1 套（CUDA）** | N 家各一套，互不兼容 |
| 适配成本 | **O(1)** | O(N)，长期维护 N 份 |
| 复用率 | **高** | ≈0（客户被指定厂商绑定） |
| 客户选择自由 | **有**（市场化采购） | 无（政策/目录指定） |
| 核心卖点是否成立 | **成立**（中立选择有价值） | **不成立**（无需选择自由） |
| 可规模化 | 产品化，边际成本递减 | 项目制定制，边际成本不降 |
| 软件预算占比 | 企业侧真实 | 政企侧占比低 |
| 标准化 | 容器/CUDA 生态统一 | 各家割裂，无统一互联与计量标准 |
| 交付形态 | 产品 + 订阅 | 一次性集成项目 |
| 合规/地缘风险 | 低 | 高 |

### 三条结论
1. **商业不成立**：核心价值"跨厂商中立选择"在该场景不存在
2. **难成立**：N 套不兼容栈 + 一客户一定制，无规模效应
3. **低价值**：软件预算占比低，且多为项目制而非可复制产品

**唯一窄可行**：国家级/省级算力中心或大型云厂商**内部平台**——
但那是自研/项目制，非独立软件产品市场。

## 5. 关于 Apple 算力融合（已搁置）

曾评估过 Mac ↔ NVIDIA 混编（竞品空白、痛点真实），
但**当前战略聚焦 NVIDIA 全系列异构**，该方向暂不推进。

- 代码层保留 `apple-silicon` family 支持（无害，未来可启用）
- 相关设计文档**未上传**，本地封存并标注"已搁置"
- 如未来重启，其价值在于"别人做不了"的差异化楔子

---

## 6. 目标客户（按契合度）

| 需求方 | 痛点 | 契合度 |
|---|---|---|
| **城市算力中心 / 政务云** | 多厂商设备无法统一调度计费 | **最高** |
| 中大型企业 IT/AI 平台 | 并发一上来就崩、单 token 成本高 | 高 |
| 行业 SI（医疗/政务/金融） | 硬件预算被压 | 高 |
| AI 应用创业公司 | API 账单吃掉毛利 | 中高 |
| 运营商 / 边缘云 | 回源带宽与中心压力 | 中 |
| 高校 / 科研平台 | 多课题组共享算力无配额 | 中低 |

## 7. 对外口径（务必守住）

- 定位表述：「跨硬件中立的算力编排与计量」
- 涉及国产算力：**只做商业结构性说明，不做延伸评价**
- 已实现的说已实现，**未接入主链路的不得说"已生效"**
- **当前无付费客户**——本文为定位分析，非需求验证
- 不得把"市场很大"表述为"我们有客户"
