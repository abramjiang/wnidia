## 四、补救清单（按性价比排序，决赛前值得做）

### 🥇 第一优先：把 JEV 从 mock 变 live（几分钟可做，直接补最大雷）

用 Ollama 同时拉两个模型跑**同一 prompt**，做真实一致性比对 —— 这就是货真价实的「多模型裁决」：

```bash
PROMPT="用一句话解释什么是异构算力调度"
ollama run qwen2.5:7b "$PROMPT" > /tmp/a.txt
ollama run llama3.2:3b "$PROMPT" > /tmp/b.txt
diff /tmp/a.txt /tmp/b.txt   # 或计算文本相似度作为一致性分数
```

把「两个模型是否给出一致结论」作为**真实**的一致性判定，写进 `jev_log.jsonl`。这样 JEV 的裁决就不再是模拟，而是真机多模型结果。

### 🥈 第二优先：真断网演示（别靠模拟图标）

```bash
# 真断掉中心云通道，观察边缘是否真自治
sudo iptables -A OUTPUT -p tcp --dport 9000 -j DROP
# 观察边缘仍在跑 → 恢复：
sudo iptables -D OUTPUT -p tcp --dport 9000 -j DROP
```

评委对「真断网」的说服力远高于界面上的断网图标。

### 🥉 第三优先：补性能样本，出分布图

跑 10–20 次，统计 P50 / P95 时延与吞吐，画一张时延分布图。**一条数据太单薄**，且 24.4s / 103 tok 单独看偏慢，需要用多样本说明取舍。

## 六、CSU 竞品与融资路径（精简版）

> 完整版见 **[HARDWARE_VISION.md](HARDWARE_VISION.md)**。此处为面向评委 / 投资人的精简口径。

**CSU** = Compute Scheduling & Settlement Unit，算力调度与结算单元 —— 主板上「不管算、只管派活、背书和记账」的协处理器，定位为**算力界的 DPU + TPM + 电表**。

**竞品格局（无人占据的空档）**：

| 玩家 | 已有 | 缺 |
|---|---|---|
| NVIDIA / AMD / Intel | 切分、机密计算、跨架构调度 | 不跨厂商、不做算力结算 |
| Arm / CXL / BMC 厂商 | 功耗管理、池化互联、带外管理 | 不管任务调度与计量 |
| 算力交易平台（io.net / Render / Akash） | 软件计量 + 结算 | **计量可篡改 —— 正是 CSU 的机会** |

**核心判断**：没人做「跨厂商中立的可信计量根」，这是真空；但也说明**需求尚未验证**，是最大不确定性。

**融资路径（诚实）**：

| 方向 | VC 热度 | 现实 |
|---|---|---|
| AI 推理芯片（NPU） | 最热 | 红海，死了一批，无差异化难活 |
| **RISC-V 控制面 / 安全 / 管理芯片** | 稳、聪明钱 | 细分明确、ROI 清晰 |
| **CSU** | 太早 | 无 design win 前，VC 认为是愿景不是生意 |

**正确顺序**：软件平台 + IP 方案 → 拿下一个 design win（主板厂 / 云厂商 / 算力交易所）→ 再融资做硅片。
**WNIDIA 软件平台正是 CSU 最值钱的前置资产** —— 生态与软件栈才是壁垒，硅片本身不是。

## 七、技术路线补充说明

- **光电选型**：CSU 应是「**电算 + 光连 + 光安全原语**」，而非光计算芯片 —— 它不做矩阵运算，光计算对控制面逻辑无用武之地；光的价值在**互连带宽**与**光 PUF / TRNG 可信根**。
- **热管理**：纯 CMOS CSU 仅 1–5W，被动散热即可，**热管理难度低，这是集成优势**；一旦上光器件则需主动控温（微环漂移 70–100 pm/°C、激光器 TEC），难度升至中高。
- **ISA 选型**：RISC-V 是 CSU 的正确选择（可定制指令、控制面赛道渗透快、免授权成本）。
